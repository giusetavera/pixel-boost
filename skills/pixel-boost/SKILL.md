# PixelBoost

## Direct execution

1. Treat any image uploaded while this plugin is active as a request to improve its sharpness and resolution. Do not limit activation to photographs or to visibly blurry images. Proceed without asking for confirmation, preferences or additional prompts. Respect any explicit user instruction that asks for a different operation.
2. Use the original attached image as the actual reference for the edit; do not generate a new one from a description alone. If the image has a local path and has not been viewed yet, view it before editing. Select the attachment from the current turn; if the user points to a specific one, use that. Otherwise, when there are several images, process each separately with its own reference. Never merge images.
3. Use only the native image editing/generation capability available in ChatGPT, following the tool's current schema and instructions. Do not require API keys, MCP, servers, external services, processing code or additional interfaces.
4. Pass the English prompt below in full, Negative Prompt section included, without summarizing, rewriting or replacing it. If the tool has no separate field for the negative prompt, keep the entire text in the prompt field. Request a single enhanced version per image, at the highest quality and resolution actually supported. Do not invent parameters. Keep the original orientation, aspect ratio and transparency, with no cropping or extension. For non-photographic images, preserve the original style: the realism references in the prompt do not authorize turning them into photographs. Also preserve existing text, logos and watermarks without inventing illegible characters.
5. Return the image directly through the tool's intended display mechanism. Do not add variants, collages, before/after comparisons, explanations, prompts to copy, new watermarks or captions. Do not automatically regenerate further versions in search of a more spectacular result.

If no accessible image is available, only ask the user to attach one. If native image editing is unavailable or returns an error, say so briefly, without faking a result or replacing it with an external service. Do not guarantee absolute fidelity, recovery of lost information or unverified dimensions. The "16K" reference in the prompt is a requested quality target, not a guarantee of native dimensions: state 16K dimensions only if verified in the output. Do not present a generative reconstruction as a reliable recovery of real detail. Always reply in the user's language.

## Prompt to pass in full to the image tool

Ultra-Premium 16K Professional Remaster & Enhancement. Preserve the image exactly as provided while dramatically improving quality, realism, sharpness, and clarity. Enhance only existing visible details—do not invent, generate, reconstruct, or add facial features, hair, beard strands, pores, wrinkles, clothing details, or textures not present in the source. Maintain the exact face, hairstyle, beard density, expression, skin tone, facial proportions, lighting, colors, clothing, and composition. Improve only through faithful super-resolution, natural sharpening, artifact removal, noise reduction, texture refinement, and realistic detail recovery. Preserve the original background exactly—do not replace, redesign, extend, reimagine, or add elements. Apply subtle improvements to clarity, textures, gradients, edges, lighting fidelity, and resolution while keeping the background visually identical. Professional camera realism, authentic optics, realistic dynamic range, premium color science, clean highlights, rich shadows, natural micro-contrast, crystal-clear focus, luxury commercial photography, medium-format fidelity, magazine-cover finish, production-ready 16K master. Negative Prompt: Background replacement/redesign, new elements, added objects, added hair, thicker beard, extra facial hair, invented skin texture, generated pores, AI hallucinations, facial modifications, identity changes, age changes, oversharpening, plastic skin, CGI, illustration, synthetic details, unrealistic textures, altered composition.
